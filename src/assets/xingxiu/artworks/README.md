# 正式神像 Web 资产目录

本目录只允许存放经人工审核确认并获准进入 UI 的二十八宿神像 Web 资产。

2026-08-26 实装的 28 张 PNG 是本地审核原图的逐字节无损副本；只按现有
`assetStem` 规则改名，没有裁切、调色、抠图、压缩或其他画面处理。原始审核资料
不属于公开仓库。

未经同等人工审核的原塑摄影、造型挂轴、现代复制品、网络采集图片或历史生成候选图禁止进入本目录。正式资产缺失时由界面显示统一空状态，不得从任何参考或候选目录自动回退。

## 低网速派生图

每个正式 PNG 可由 `npm run generate:mobile-deity-artworks` 生成同名的
`*.mobile.webp` 派生图。生成规则固定为最长边 840px、WebP quality 84，保留 PNG
作为唯一高清源文件；脚本会跳过已存在的派生图，传入 `--force` 才会重新生成。
该脚本使用本机 WebP 命令行工具 `cwebp`，用于维护时无需提供第二套业务素材。慢网时该版本在所有设备上使用。
