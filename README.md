# 二十八星宿星图系统

[English](README_EN.md)

> **Twenty-Eight Mansions Star Map** — 以中国传统二十八宿与星官体系为核心的交互式 Web 星空。

本项目把现代恒星坐标、二十八宿、传统星官关系、文化档案与经过人工审核的二十八星宿数字神像放进同一个可交互、可核查的浏览器体验。用户可以在三维观测视角与固定全天投影之间切换，改变日期和时间，浏览四象二十八宿，并打开北斗九星、南斗六星、三台三个重要星官专题。

## 项目愿景

以现代 Web 可视化呈现二十八宿、传统星官及其文化资料，同时保留天文空间关系、资料来源和历史不确定性。项目定位是文化展示与资料导览，不提供玄学商业服务，也不把当前映射宣称为唯一历史定本。

## 在线体验

[打开二十八星宿星图](https://sentomohiro.github.io/twenty-eight-mansions-star-map/)

## 项目缘起

维护者负责产品方向、传统文化资料核对、神像逐张人工审核以及最终视觉与文化验收；GPT / Codex 协助工程实现、数据整理、代码修改、测试与调试。领域判断以可核查资料和维护者审核为准，AI 不作为传统文化事实的权威来源。

## 核心功能

- 三维天球观测与固定全天投影，可拖动、缩放并切换视角。
- 东方青龙、北方玄武、西方白虎、南方朱雀四象与二十八宿统一数据模型。
- 日期、时刻、观测地点与地平坐标转换；定位失败时安全回退到阳城参考视角。
- 二十八宿选择、高亮、神像舞台与文化档案。
- 28 张经过人工逐张审核确认的正式数字神像。
- 完整中国传统星空背景与来源披露。
- 独立的“重要星官”文化层：北斗九星、南斗六星、三台。
- 北斗成员选择、南斗与斗宿共享恒星语境、三台上／中／下台子组选择。
- 桌面、平板和手机响应式布局。

## 数据与文化原则

项目明确区分以下层次：

1. 现代恒星标识、坐标与星等；
2. 中国传统星官关系与历史图式；
3. 二十八宿文化体系；
4. 道教星斗信仰与神格称谓；
5. 后世民俗或术数体系。

古今恒星映射、古籍传本和星君尊号可能存在差异。数据层为来源、映射说明和置信度保留字段；资料不足时宁缺毋滥。例如北斗“弼星”只作为传统文化星位展示，明确标记“现代恒星对应未作确定”，不会为凑足九个真实点而伪造 HIP 身份。

## 神像素材说明

正式网站使用的是经过人工逐张审核确认的二十八星宿数字插画资产。造型研究遵循“官方元代原塑摄影 > 元代原塑造型挂轴参考 > 现代彩塑复制品”的证据优先级；挂轴资料不被称作“元代原塑原始摄影”。本地审核参考资料不进入公开仓库。

## 设计原则

- 简单稳定，数据与表现分离，配置驱动。
- 28 宿和重要星官共用通用组件，不为每个对象硬编码页面。
- 不依赖登录、数据库、CMS 或自建后端。
- 视觉品质优先，同时避免与文化展示无关的过度工程化。
- 对资料差异与现代映射不确定性作显式说明。

## 本地运行

需要 Node.js 20.19+ 或 22.12+（推荐当前 Node.js 22 LTS）。

```bash
npm install
npm run dev
```

## 测试与质量

```bash
npm run typecheck
npm run lint
npm test
npm run build
```

还可以运行 `npm run audit:stellarium-song`，复核公开 Stellarium 中国宋代星空快照的结构统计。

## 公开项目结构

